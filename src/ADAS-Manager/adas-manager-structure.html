Convenção de build

Todos os módulos são header-only (declaração + implementação juntas), incluídos diretamente por adas_manager.cpp. O Makefile continua a compilar uma única unidade de tradução — zero mudança de build ao longo dos 5 passos.

Onde só funciona em AUTONOMOUS

obj_throttle_limit e v2i_throttle_limit só têm efeito dentro de autonomous_driving(). Em modo MANUAL, o joystick manda direto — sinais e V2I são ignorados por desenho.

Compilação cruzada

can_sender.hpp / can_receiver.hpp dependem de linux/can.h, só existe no target Linux embarcado — build de verificação sintática no Mac falha aí por desenho; teste real sempre no carro.

branch refactor/ADAS-modular-restructure — 5 passos de extração + porte do V2I do colega por cima do estado atual (ACC, curve slowdown, status_thread e deadlock-breaker do EMERGENCY_STOP mantidos).
