# Issue Step by Step

Este guia mostra como registar e tratar problemas sem perder contexto.

## 1) Descrever o sintoma
- Dizer exatamente o que falhou.
- Indicar em que fase aconteceu.
- Dizer se a falha é reprodutível.

## 2) Fixar o contexto
- Anotar modelo, `HEF`, cenário, ramo e data.
- Guardar o comando ou sequência que levou ao problema.

## 3) Tentar reproduzir
- Repetir o erro com o mínimo de variáveis possível.
- Confirmar se o problema depende de resolução, input ou ambiente.

## 4) Testar hipóteses
- Alterar uma variável de cada vez.
- Registar o efeito de cada tentativa.
- Não misturar correções sem saber qual resolveu.

## 5) Fechar a issue
- Explicar a causa raiz, se for conhecida.
- Descrever a solução aplicada.
- Indicar impacto nos benchmarks ou no E2E.

## 6) Resultado esperado
- Problema documentado com contexto suficiente para reaparecer sem ambiguidade.
