# Overview Step by Step

Este guia mostra a ordem certa para usar a documentação Hailo sem perder contexto.

## 1) Começar pelo contexto
- Ler `../context/context.md` para perceber o projeto, o hardware e as restrições.

## 2) Confirmar o objetivo
- Ler `project_scope.md` para saber qual é o problema real que estamos a resolver.

## 3) Ir para a execução
- Seguir `../10_setup/setup_step_by_step.md` antes de mexer em conversão ou benchmark.

## 4) Avançar por fase
- Converter com `../20_conversion/conversion_step_by_step.md`.
- Medir com `../30_benchmarks/benchmark_step_by_step.md`.
- Narrar o fluxo com `../40_e2e/e2e_step_by_step.md`.

## 5) Fechar o ciclo
- Registrar issues em `../50_issues/issue_step_by_step.md`.
- Atualizar o plano em `../60_planning/planning_step_by_step.md`.
- Indexar evidência em `../90_history/evidence_step_by_step.md`.

## 6) Resultado esperado
- Uma leitura linear que leva da visão do projeto à execução real.
